# UESLocker

## About the Project
UESLocker is a fast, secure, and user-friendly web-based utility designed for text encoding and decoding. Engineered with a focus on privacy and performance, the application operates entirely on the client side, ensuring that no sensitive data is transmitted to or stored on any external servers. The project is hosted via GitHub Pages and optimized for a seamless experience across all device sizes.

## Key Features
* Reliable text encoding and decoding operations.
* Secure client-side architecture (zero server-side data processing).
* Fully responsive layout tailored for mobile, tablet, and desktop environments.
* Minimalist, lightweight, and intuitive user interface.
